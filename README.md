# Web-sovellusten perusteet harjoitustyö

## Online Games Site

- Music Quiz
- Memory Game

## Music Quiz

In the Music Quiz, you are given a music related question and 4 options. Select the right answer and you go on to the next round. At the start you can choose your difficulty from 3 options. 
The questions used in the quiz are fetched from Open Trivia Database. High scores at the end are stored in browser's local storage.

1. Go to my Github Pages site: [link](https://c3hoju00.github.io/web-sovellusten_perusteet/index.html)
2. Choose the Music Quiz.
3. Type in your nickname and choose the difficulty.
4. Start the game!

## How to play Memory Game

In the Memory Game, you are shown a number that you need to memorize within 5 seconds. When the time is up, you need to type in the number to the input field with no spaces. If you remember the number correctly, you move to the next round and one number is added. 

1. Go to my Github Pages site: [link](https://c3hoju00.github.io/web-sovellusten_perusteet/index.html)
2. Choose the Memory Game.
3. Type in your nickname.
4. Start the game!
